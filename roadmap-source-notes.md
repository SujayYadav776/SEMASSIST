# Roadmap Source Notes

## Python roadmap

Source: https://roadmap.sh/python

The rendered roadmap sequences Python through basic syntax, variables and data types, operators, strings, conditionals, loops, functions, builtin functions, exceptions, lists, tuples, sets, dictionaries, comments, and type annotations. It then covers data structures and algorithms, modules, package managers, object-oriented programming, functional/paradigm features, environments, configuration, static typing, code formatting, documentation, testing, I/O, and concurrency. It subsequently branches to frameworks and related backend, DevOps, and AI/data paths. The dashboard keeps the foundations-to-concurrency sequence as this semester’s core and labels framework study as a later-stage checkpoint.

## Java roadmap

Source: https://roadmap.sh/java

The rendered roadmap sequences Java through fundamentals (syntax, program lifecycle, data types, variables/scopes, strings, methods, math, arrays, type casting, conditionals, loops), object-oriented programming, classes and objects, language structure, collections and generics, exception handling, build tools, I/O, concurrency, functional programming and streams, networking, database access, logging, testing, documentation, dependency injection, and frameworks. The dashboard prioritizes this foundation-through-testing sequence and labels JDBC/database access and Spring Boot as subsequent checkpoints.

## Dashboard mapping decision

The revised dashboard will use roadmap-aligned checkpoint groups. Its current-semester tasks will track only the high-priority foundation layers, while clearly labelling advanced frameworks, database access, and API work as subsequent stages. This retains fidelity to the provided roadmaps without diluting the user’s Python–Java–Operating Systems focus.
